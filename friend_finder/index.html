    👥 Friend Finder & Peer Matching Dashboard (v2)

    Live Application Link: https://friend-finder-v2-mb.streamlit.app/

    📝 Project Overview

    Friend Finder & Peer Matching Dashboard is an innovative, data-driven application that utilizes unsupervised machine learning to connect people with similar traits, hobbies, and interests. Based on an expanded survey dataset (v2), the app automatically groups participants into distinct peer communities.

    Instead of relying on basic keyword filtering, I implemented an AI-Native clustering pipeline. Users input their demographic details, preferred locations, and favorite animals, and the system instantly matches them with their closest community. By feeding the statistical centroids of each cluster into OpenAI's Large Language Models (LLMs), the application dynamically synthesizes warm, relatable group names and behavioral profiles (e.g., "Miłośnicy Lasów i Psów"), helping users discover how many like-minded friends they have within the dataset.

    🚀 Core Features & ML Methodology

    The updated v2 pipeline integrates advanced data grouping, cluster profiling, and automated generative AI text enrichment:

    📊 1. Multi-Dimensional Peer Clustering & EDA

    • Exploratory Data Analysis: Conducted a rigorous initial analysis using Seaborn and Matplotlib to map out customer demographics and profile behavior patterns across different user categories.
    • Optimal Group Identification: Developed an unsupervised learning pipeline to automatically cluster survey respondents into 8 distinct interest-based peer communities.
    • Centroid Profiling: Extracted the precise statistical averages for each group, defining the common traits, shared locations, and unique habits that connect people within each cluster.

    🤖 2. Generative AI Community Profiling

    • OpenAI LLM Integration: Automated the interpretation of abstract mathematical groups by passing the statistical distribution of each cluster to OpenAI's models via engineered prompts.
    • Dynamic Group Descriptions: The system automatically crafts engaging group names and friendly summaries, explaining the shared profile of the community you belong to.

    🛠️ 3. Cloud Deployment & Iterative Upgrades

    • Streamlit Cloud Infrastructure: Successfully migrated and deployed the modern dashboard architecture onto the Streamlit Community Cloud for public access.
    • Iterative Core Updates: Upgraded the underlying models and raw data assets from the original codebase to the newer v2 standard.

    🛠️ Infrastructure & Tech Stack

    • Frontend & UI: Streamlit (Python-native interactive community dashboard).
    • Automated Machine Learning: PyCaret (used for rapid prototyping, model conversion, and real-time user-to-cluster assignment via predict_model).
    • Data Visualization: Plotly Express (for production-ready dynamic charts) and Seaborn / Matplotlib (for analytical EDA phase).
    • Generative AI Enrichment: OpenAI API (GPT models for automated community name and profile synthesis).
    • Cloud Deployment: Streamlit Community Cloud (Python 3.11 environment optimized with fixed environment dependencies).
